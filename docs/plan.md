# Проєкт: Персональний сайт нейрохірурга

## Мета
Створити сучасний, швидкий, довіру-викликаючий сайт-візитку для практикуючого 
нейрохірурга. Головна аудиторія — пацієнти, які шукають спеціаліста. Ключова дія — 
запис на консультацію через просту форму.

## Технічний стек
- Next.js 14+ (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui для UI-компонентів
- react-hook-form + zod для форми та валідації
- Деплой розрахований на Vercel
- Форма надсилає заявку на email через API route (використай Resend; винеси ключ у 
  .env, зроби заглушку якщо ключа немає)

## Вимоги до якості
- Повністю адаптивний (mobile-first) — більшість пацієнтів зайдуть з телефона
- Оптимізований під SEO: семантична розмітка, метатеги, Open Graph, 
  structured data (JSON-LD schema.org/Physician)
- Швидкий: статична генерація сторінок де можливо, оптимізація зображень через 
  next/image
- Доступність (a11y): коректні aria-атрибути, контраст, навігація з клавіатури
- Чиста, підтримувана структура компонентів

## Дизайн
- Стиль: чистий, професійний, медичний, але тепло-людяний (не холодно-корпоративний)
- Палітра: спокійні кольори, що асоціюються з довірою та медициною 
  (глибокий синій / бірюзовий як акцент, багато білого простору)
- Типографіка: читабельна, сучасна
- Тон: спокій, компетентність, турбота
- Використай плейсхолдери для фото (позначені зони під реальні зображення)
- Весь текстовий контент — плейсхолдери [У КВАДРАТНИХ ДУЖКАХ], які легко замінити

## Мова
Весь контент сайту — українською.

## Структура сайту

### 1. Головна сторінка (/)
- Hero-секція: ім'я лікаря, спеціалізація, коротке позиціонування, 
  CTA-кнопка «Записатися на консультацію», місце під портретне фото
- Короткий блок «Чим допомагаю» (основні напрямки роботи)
- Блок довіри (роки досвіду, к-сть операцій, регалії — короткі цифри)
- Секція з коротким «Про лікаря» + кнопка на повну сторінку
- Блок відгуків (заготовка під 2-3 відгуки)
- Фінальний CTA із формою запису (або кнопкою до неї)
- Футер: контакти, адреса, месенджери, соцмережі

### 2. Про лікаря (/about)
- Портрет + повне ім'я, титули
- Біографія, освіта, стажування
- Досвід, спеціалізація
- Наукова діяльність, публікації, членство в асоціаціях
- Особистий блок «чому нейрохірургія» (заготовка)

### 3. Напрямки роботи / підхід (/services)
- Перелік проблем/діагнозів, з якими працює (простою мовою)
- Список процедур/операцій
- Блок «Як проходить лікування»: шлях пацієнта покроково 
  (консультація → діагностика → рішення → операція → відновлення)
- Що взяти на консультацію

### 4. Форма запису на консультацію
Реалізуй як окрему сторінку (/appointment) І як вбудований компонент, який можна 
розмістити на головній.
Поля:
- Ім'я та прізвище (required)
- Номер телефону (required, з валідацією формату)
- Опис проблеми (required, textarea)
- Чекбокс згоди на обробку персональних даних (required) з посиланням на 
  політику конфіденційності
Логіка:
- Валідація через zod
- При сабміті — надсилання на email лікаря через API route
- Стани: loading, success (подяка + що буде далі), error
- Захист від спаму (хоча б базовий: honeypot-поле)

### 5. Політика конфіденційності (/privacy)
Окрема сторінка-заготовка під текст політики обробки персональних даних 
(медичні дані = чутливі, GDPR-сумісність).

## Компоненти
Винеси в перевикористовувані компоненти: Header з навігацією, Footer, 
AppointmentForm, ServiceCard, TestimonialCard, TrustStats, CTASection.

## Структура проєкту
Організуй за feature-based підходом, з чіткою структурою app/, components/, lib/.
