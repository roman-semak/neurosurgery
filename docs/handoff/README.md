# Синхронізація дизайну з кодом

## Разова передача
1. Скопіювати `tailwind.config.ts` і `globals.css` у Next.js-проєкт.
2. Перенести SVG з `assets/` у `components/vessels/` як React-компоненти.
3. Верстати за `design-spec.md`, звіряючись із живим макетом
   `Скорохода - мобільний сайт.dc.html`.

## Регулярна синхронізація
Підключіть репозиторій до цього проєкту (GitHub або локальна папка) — тоді я зможу
читати реальні компоненти, звіряти макет із кодом і оновлювати його після кожних змін.
У цій сесії доступ до папки «neurosurgery» не піднявся; спробуйте перепідключити її.
